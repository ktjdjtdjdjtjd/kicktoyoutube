# 天狗ちゃん 9/6配信 雑談総集編 CapCut用パック

`clips/2866728770_timestamps.md` の雑談切り抜き候補17区間を**全採用・時系列順**で繋いだ前提の素材。
総尺 **1:06:50**。生成コマンド: `python scripts/clip_pack.py --uuid 2866728770 --segments clips/2866728770_pack/segments.csv --out clips/2866728770_pack`

| ファイル | 用途 |
|---|---|
| `cutlist.csv` | 採用17区間。`src_in/src_out`=元動画の時刻、`timeline_in/out`=繋いだ後の位置 |
| `compilation.srt` | 繋いだ後のタイムラインに合わせた字幕（891キュー）。字幕テンプレ差し替え用 |
| `chapters.srt` | 区間ごとの見出しを区間全体に載せた字幕（17キュー）。チャプターテンプレ差し替え用 |
| `chapters.csv` | チャプター一覧（位置+見出し） |
| `segments/NN_*.srt` | 区間単体の字幕（区間先頭=00:00:00）。区間ごとに別クリップで扱う場合用 |
| `segments.csv` | 区間定義（順序・in/out・見出し）。並びや境界を変えたらこのCSVを直して再生成 |

## CapCut「編集」シーケンスでの手順
1. 動画データ（元配信、0秒=配信開始）を `cutlist.csv` の `src_in`〜`src_out` で17回分割し、`order` 順に隙間なく並べる。
   元動画がYouTubeアーカイブ（p8FgewWNhcg）でもTwitch VODでも時刻は同じ（アーカイブはVODと同じ0秒起点）。
2. 字幕: 「テキスト → ローカル字幕をインポート」で `compilation.srt` を読み込み、タイムライン0秒に置く。
   その後、字幕トラックを選択して「テンプレ置き場」の字幕テンプレのスタイルを適用（テンプレをコピー→字幕に「スタイルを適用」）。
3. チャプター: `chapters.srt` を同様にインポートし、別トラックに置く。各キュー（=各区間の頭）にチャプターテンプレを差し替え、
   表示は先頭3〜5秒だけ残して短くする（SRTでは区間全体に伸ばしてあるので、頭出し位置の目印として使う）。
4. レビュー時に区間の境界を動かした場合は `segments.csv` を直して再生成すれば字幕・チャプターの位置も追従する。
