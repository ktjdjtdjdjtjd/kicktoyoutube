## 5. 既知の制約・注意
- **クラウドセッションからは YouTube / Twitch に接続できない**（プロキシで403）。動画DL・文字起こしは GitHub Actions の `chapters.yml`（uuid指定で手動起動）で行った。フル画質DLは手元PCで `yt-dlp -f "Source/best" https://www.twitch.tv/videos/2866728770` が最短。Twitch VODは自動削除されるので早めに。
- CapCut はクラウドから操作できない。CapCut内の作業（分割・SRTインポート・テンプレ適用）はユーザーのPC上で行う前提。CapCutのドラフトJSONを直接生成する案は仕様が不安定なので採用していない。
- 字幕本文は文字起こしそのまま。誤認識多め。定番置換（オーバーボッチ→オーバーウォッチ、ペンク/ヘンク/エング/ヘンゲちゃん→天狗ちゃん 等）は `scripts/clip_pack.py` の `REPLACE` で実施。時刻精度 ±1〜2秒。
- 区間#15の後半（元動画 3:41:53〜）は他配信者の不倫・処分に言及。カットするなら 3:41:50 で止める。
- 元動画0秒=配信開始。YouTubeアーカイブもTwitch VODも同じ起点なので cutlist の時刻はどちらにも使える。
- 天狗ちゃん切り抜きチャンネルの既存動画はネットワーク制限で参照できていない。「会話が主役の区間を優先」の一般基準で選定。
- chapters ワークフローの通常動作で、Gemini生成の粗い章立てがYouTube説明欄に自動反映されている可能性がある。細かい版に差し替えるなら `clips/2866728770_timestamps.md` の1章を貼る。
